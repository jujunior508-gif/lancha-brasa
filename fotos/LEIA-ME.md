# Fotos do cardápio

Coloque aqui as fotos dos lanches. Depois adicione, no `app.js`, `foto:'fotos/NOME-DO-ARQUIVO.jpg'` no item correspondente (procure por `COMO EDITAR O CARDÁPIO`).

Exemplo, para o Brasa Clássico:

```js
{id:'classico',foto:'fotos/classico.jpg',cat:'burgers', ...
```

Dicas para ficarem bonitas:
- Formato horizontal, de preferência 1200 × 960 px (proporção 5:4). O site corta as bordas para caber.
- Lanche centralizado, fundo escuro ou neutro, luz vinda de lado.
- Arquivo `.jpg` ou `.webp` com até ~200 KB, para o site continuar rápido.
- Use nomes sem espaço e sem acento (ex.: `smash-duplo.jpg`).

Se uma foto não for encontrada, o site mostra a ilustração no lugar.
